# PA6 – README

## How to Run

1) Open the notebook in Google Colab  
2) Run all cells in order from top to bottom (the order matters)
3) Then the data will load and be processed by Pyspark and then show the output and save the results in the cloud


## Configuration
This project uses PySpark in Google Colab to run the code and show the outputs. Then the results are then saved to Google Cloud


## Input Data

The input data is stored in Google Cloud Storage at

datascrapers-team04/Beauty_and_Personal_Care.jsonl.gz


## Output Data

The output data is saved to Google Cloud Storage at

datascrapers-team04/pa6_outputs/


## Code and Files

The main code is in the notebook file. There are no separate scripts or helper files.
